# EducaZap Finance

**Educação financeira gamificada no Instagram com IA**

Landing page institucional do EducaZap — plataforma de educação financeira para famílias de baixa renda em Mato Grosso, desenvolvida com apoio do Programa Centelha MT / FAPEMAT / FINEP / CNPq.

## Sobre o projeto

O EducaZap é uma plataforma de educação financeira gamificada integrada ao Instagram, com trilhas de aprendizado personalizadas por Inteligência Artificial, simuladores de investimento com dados reais do Banco Central (BACEN) e controle financeiro pessoal — tudo dentro do Direct do Instagram, sem necessidade de baixar aplicativos.

## Tecnologias

- HTML5 + CSS3 + JavaScript puro
- Google Fonts (Bricolage Grotesque + Plus Jakarta Sans)
- Integração com API BACEN SGS (Selic, CDI, IPCA, Dólar)
- Dados exclusivos CISE/UNEMAT (IPC-Sinop, Cesta Básica)
